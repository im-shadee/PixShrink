# PixShrink - Changelog

## [1.2.0-beta] - 10/10/2026

### Features
- Added log files (/Logs/ folder) detailing process errors/outputs each step of the compression to facilitate user reports,
- Added batch compression support in the compressor,
- Added batch selection (drag-and-drop/add,remove,clear buttons),
- Revamped UI yo account for the new batch selection system,
- Added a loading bar to show compression progression to the user,
- Reinforced application reliability with additional try/catch blocks notably during critical and important async operations.

## [1.1.0-beta] - 07/10/2026

### Features
- Added support for posterization (with warnings in case dithering is too high, dynamic element display),
- Added color modes inspired by gimp (i.e. RGB, Grayscale, Indexed),
- Refactored architecture for maintainability.
